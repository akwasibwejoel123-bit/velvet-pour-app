# Velvet Pour
React Native/Expo starter for the Velvet Pour customer app and admin product catalogue.

## Run
npm install
npx expo start

## Included
Customer home, cocktails, liquor, non-alcoholic catalogue, cart, local order flow, event request form, and admin product add/delete.

## Production integrations still needed
Secure authentication, cloud database, image storage, real payment provider, delivery/rider integration, push notifications, legal/privacy documents, production QA, signing and store submission.
